\section{Introduction}
American Sign Language (ASL) is a visual language primarily used by the deaf and hard of hearing. Automatically recognizing ASL gestures offers numerous societal benefits, including improved accessibility in communication technologies.

This study explores the use of hand landmark detection and machine learning to classify hand gestures from ASL. Using Mediapipe's hand tracking capabilities and a supervised classifier trained on extracted landmarks, we aim to identify which model and normalization techniques yield the highest accuracy.

The central research questions are:
\begin{enumerate}
    \item Which machine learning model achieves the highest classification accuracy on ASL letter recognition?
    \item Which normalization techniques enhance the model's robustness to variations in hand position, size, and lighting?
\end{enumerate}

\section{Methods}
The ASL letter detector consists of two primary components:
(1) a hand landmark detector using Mediapipe's pre-trained
model, and (2) a custom trained model to predict the ASL
letter based on the provided hand landmarks. This section
describes the system architecture and data processing pipeline
in detail.

\subsection{Pipeline Overview}
The data processing pipeline includes:
\begin{itemize}
    \item \textbf{Image Acquisition}: Using a static dataset or webcam capture.
    \item \textbf{Hand Landmark Detection}: Mediapipe detects 21 hand landmarks (x, y, z) per frame or image.
    \item \textbf{Normalization}: Optionally translating the landmarks so the wrist is at the origin and scaling by wrist-to-middle-finger distance (or other strategies).
    \item \textbf{Feature Vectorization}: Flattening the \((x,y,z)\) coordinates into a 63-dimensional vector for each hand.
    \item \textbf{Model Inference}: A machine learning classifier predicts which ASL letter the vector corresponds to.
\end{itemize}

\subsection{Software Architecture}
\textbf{\texttt{load.py}}: Handles data ingestion and preprocessing. It uses Mediapipe to extract landmarks, applies normalization, and returns feature vectors with associated labels. The output is stored in a CSV file for training.

\textbf{\texttt{train\_model.py}}: Imports the CSV, applies a train/test split, and trains various classifiers including \texttt{KNeighborsClassifier}, \texttt{RandomForestClassifier}, \texttt{SVC}, and \texttt{LogisticRegression}. Models are saved using \texttt{joblib}.

\textbf{\texttt{predict\_live.py}}: Performs real-time predictions using OpenCV and Mediapipe. It loads the trained model and applies the same preprocessing steps on live webcam input for instant classification feedback.

\textbf{\texttt{run\_experiments.py}}: Gathers several experiment routines, such as comparing multiple models, testing various normalization strategies, performing dimensionality reduction (PCA/t-SNE) for visualization, and optionally conducting cross-user validation.

\section{Experimental Results}

\subsection{Datasets}
To train the model, a dataset containing 1,728 images of ASL letters under varied conditions was used. This included both colored and grayscale images, with different brightness levels and multiple users. Auto-orientation corrections were applied, and images were resized to 640x640. Approximately 300 images were excluded because the hand landmarks could not be reliably detected (e.g., occlusion or poor lighting). The final working dataset thus contained around 1,400 labeled images.

\subsection{Implementation Details}
\begin{itemize}
    \item \textbf{Data Augmentation}: Horizontal flipping to simulate left/right hands and to increase dataset size. This approach aims to improve the model's generalization to mirror-image gestures.
    \item \textbf{Normalization}: Translation of landmarks around the wrist and scaling by a reference distance (e.g., wrist-to-middle-finger). This process is designed to mitigate scale and position variability arising from differing camera distances and hand sizes.
    \item \textbf{Train/Test Split}: An 80/20 stratified split is used, ensuring an even distribution of classes in both training and test sets.
    \item \textbf{Models Tested}: We focus on four distinct classifiers: K-Nearest Neighbors, Random Forest, Support Vector Machine, and Logistic Regression. Each model is configured with standard hyperparameters as a baseline.
\end{itemize}

\subsection{Experimental Design}
Experiments were conducted to address both research questions. We systematically varied the classification algorithm (KNN, Random Forest, SVM, Logistic Regression) and the normalization strategy (none, translation, translation+scaling) while keeping other factors (data splitting, augmentation) constant. We recorded the following metrics for each experimental run:

\begin{itemize}
    \item \textbf{Accuracy}: The proportion of correctly classified examples.
    \item \textbf{Precision and Recall}: Computed per class and aggregated using macro-averages, indicating how effectively each model balances false positives and false negatives.
    \item \textbf{F1-Score}: The harmonic mean of precision and recall, capturing the balance between these two measures.
    \item \textbf{ROC AUC}: Where appropriate (especially for binary tasks), the area under the ROC curve can provide insights into ranking quality.
\end{itemize}

All experiments were executed via \texttt{run\_experiments.py}, which automates training, evaluation, and result logging to facilitate reproducibility.

\subsection{Discussion of Findings}
\textbf{Model Comparison}: The empirical results favor Random Forest, which indicates an ensemble-based approach can effectively handle the diversity of ASL letter shapes. KNN and Logistic Regression remain competitive, suggesting that simpler methods can still perform adequately given proper normalization and sufficient data. SVM’s lower performance may be attributed to suboptimal kernel parameters or the multi-class complexity.

\textbf{Normalization}: Despite testing multiple strategies (none, translation, translation+scaling), we observed minimal differences in performance for this dataset. This outcome might indicate that Mediapipe’s initial landmark detection is already robust to common hand-scale variations. However, future tests with more variable distances and more diverse user demographics could highlight the benefits of advanced normalization (e.g., rotation correction or dynamic scaling).

\textbf{Dimensionality Reduction}: While PCA and t-SNE provide a visual overview of cluster coherence, the partial overlap among classes suggests that additional features or domain-specific transformations could help refine separability. In practice, these techniques are most valuable for exploratory data analysis and for confirming that the data do not separate trivially.

\section{Conclusion and Future Work}
We presented an ASL recognition pipeline using Mediapipe landmarks and a suite of traditional machine learning classifiers. Based on our experiments:
\begin{itemize}
    \item \textbf{Random Forest} demonstrated the strongest performance on this dataset, achieving the highest accuracy among the four tested models.
    \item \textbf{Normalization} strategies showed minimal differences in this case, possibly due to the relatively consistent capture conditions or the robustness of Mediapipe’s detection.
    \item \textbf{PCA and t-SNE} suggest partial class clustering, but with significant overlap, indicating that the feature space may benefit from further transformations or more extensive data.
\end{itemize}
Potential directions to explore include:
\begin{itemize}
    \item \textbf{Rotation Correction}: Aligning the hand axis to remove orientation confounds.
    \item \textbf{Cross-User Validation}: Evaluating generalization to new users’ hand shapes and gestures.
    \item \textbf{Data Augmentation}: Testing additional augmentations (e.g., motion blur, varied lighting, partial occlusion).
    \item \textbf{Hyperparameter Tuning}: Especially for SVM, using grid or random search to optimize kernel and regularization parameters.
    \item \textbf{Live Testing}: Measuring frame rates, latency, and user acceptance via a real-time interface.
\end{itemize}

In conclusion, this work underscores the value of robust feature extraction (via Mediapipe) and appropriate model selection (Random Forest) for effective ASL letter recognition. Future studies can refine these methods further to improve accuracy and adaptability across diverse environments and users.
